# AI-OS

This project started as a simple desktop automation experiment.

It slowly evolved into an exploration of:

- AI agent governance
- long-term runtime stability
- shared memory systems
- multi-agent supervision

The biggest lesson so far:

> AI agents don't fail because they are weak.
>
> They fail because they cannot govern themselves.

---

## Current Direction

AI-OS is not trying to build:

- a better chatbot
- another wrapper
- another automation script

Instead, this project explores:

- how agents behave over long runtimes
- how multi-agent systems coordinate
- how runtime corruption happens
- how memory and governance affect stability
- how AI systems can supervise other AI systems

---

## Current Experiments

- Brain Layer
- AGENTS.md rule systems
- Runtime Stability Rules
- Shared Brain architecture
- Multi-agent supervision
- Constitutional governance (L0 Constitution)
- Script vision vs model vision separation

---

## Architecture Philosophy

The system follows:

- human-readable state
- no hidden runtime memory
- recoverable cognition
- shared multi-agent brain
- stability-first design

No sqlite.
No opaque state systems.
No silent recovery logic.

---

## Interesting Observation

At some point,
